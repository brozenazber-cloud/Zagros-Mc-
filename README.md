# 🏔️ Zagros MC Bot

> 🤖 ربات رسمی فروشگاه **Zagros MC** برای فروش رنک‌ها و قابلیت‌های Minecraft از طریق Telegram، با سیستم پرداخت دستی، مدیریت سفارش، کد تخفیف و پنل مدیریت.

---

## ✨ درباره پروژه

**Zagros MC Bot** یک سیستم فروشگاهی کامل، سبک و قابل توسعه برای سرور Minecraft است که با **Python** و **Aiogram** ساخته شده است.

این پروژه برای مدیریت فروشگاه سرور **Zagros MC** طراحی شده و تمام عملیات اصلی فروشگاه را از طریق Telegram انجام می‌دهد.

سیستم شامل دو ربات مجزا است:

- 🤖 **Main Bot** — مخصوص کاربران و خرید
- 🛠️ **Admin Bot** — مخصوص مدیریت فروشگاه

اطلاعات فروشگاه نیز در دیتابیس **SQLite** ذخیره می‌شود و برای اجرای آن نیازی به دیتابیس خارجی نیست.

# 🎟️ سیستم کد تخفیف

Zagros MC Bot دارای سیستم کامل Coupon است.

ادمین می‌تواند:

- ➕ ایجاد کد تخفیف
- 📝 تعیین درصد تخفیف
- 🔢 تعیین حداکثر تعداد استفاده
- 📊 مشاهده تعداد استفاده
- 🗑️ حذف کد تخفیف
- ♾️ ایجاد کد بدون محدودیت استفاده

را انجام دهد.

### مثال

```text
Code: ZAGROS20
Discount: 20%
Maximum Uses: 10
```

اگر قیمت محصول:

```text
100,000 تومان
```

باشد، مبلغ نهایی:

```text
80,000 تومان
```

خواهد بود.

وقتی تعداد استفاده به سقف تعیین‌شده برسد، کد به‌صورت خودکار دیگر قابل استفاده نخواهد بود.

# 🧾 سیستم سفارش و رسید

پس از انتخاب محصول، کاربر می‌تواند پرداخت را به‌صورت دستی انجام داده و تصویر رسید را برای ربات ارسال کند.

سیستم:

1. محصول را ثبت می‌کند.
2. کد تخفیف را بررسی می‌کند.
3. مبلغ نهایی را محاسبه می‌کند.
4. رسید را دریافت می‌کند.
5. شماره سفارش ایجاد می‌کند.
6. رسید را برای ادمین‌ها ارسال می‌کند.
7. ادمین می‌تواند سفارش را تأیید یا رد کند.
8. نتیجه برای کاربر ارسال می‌شود.

# 🔐 سیستم دسترسی ادمین

دسترسی پنل مدیریت فقط برای IDهای تعریف‌شده در متغیر:

```env
ADMIN_IDS
```

فعال است.

برای چند ادمین:

```env
ADMIN_IDS=123456789,987654321
```

هر مقدار باید Telegram User ID باشد.

# ☁️ Deploy روی Railway

این پروژه برای اجرای مستقیم روی **Railway** آماده شده است.

## 1️⃣ ساخت Repository

Repository را در GitHub بسازید و فایل‌های پروژه را داخل آن قرار دهید.

## 2️⃣ اتصال به Railway

Repository را از GitHub به Railway متصل کنید.

## 3️⃣ Variables

متغیرهای زیر را در Railway قرار دهید:

```env
MAIN_BOT_TOKEN=YOUR_MAIN_BOT_TOKEN
ADMIN_BOT_TOKEN=YOUR_ADMIN_BOT_TOKEN

ADMIN_IDS=123456789,987654321

CARD_NUMBER=YOUR_CARD_NUMBER
CARD_NAME=YOUR_CARD_NAME

SUPPORT_USERNAME=IBrOzen

DB_PATH=zagros_mc.db
```

> ⚠️ توکن ربات، اطلاعات کارت و سایر اطلاعات حساس را داخل GitHub قرار ندهید.
